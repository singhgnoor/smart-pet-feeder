## Implementation and retest order

1. Freeze `CANONICAL_PROTOCOL.md` fixtures and parser bounds; review the CRC/frame details with both firmware owners.
2. Add WROOM host tests for parser, safe feed/abort, frozen sensors and bounded top-up; add WROOM safe state/ACK/dedupe behavior.
3. Add CAM parser/command queue, ID tracking, auth provisioning, bounded HTTP bodies, and truthful status/history/SSE. Compile both boards with pinned dependencies.
4. Implement schedule/config/tare/calibration persistence and readback; then pet and camera semantics.
5. Run host tests, firmware builds, UART loopback and CAM HTTP/SSE harnesses. Verify unauthorized and malformed inputs.
6. Use isolated non-actuating hardware tests first. Physical feed/abort tests require an approved safe fixture, explicit operator authorization and supervised procedure. Re-run the entire endpoint/UART matrix before enabling hardware UI controls.
